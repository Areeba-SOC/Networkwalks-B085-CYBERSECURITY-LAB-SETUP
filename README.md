**CYBERSECURITY LAB SETUP**
## 📌 Project Overview

This project focuses on building a **virtual cybersecurity and penetration-testing lab** using VirtualBox and Kali Linux.

The goal of the lab is to provide a safe, isolated environment where security tools, network scanning, reconnaissance, and vulnerability assessment can be practiced and repeated without any risk to real systems.

The lab runs on a private NAT Network, with Kali Linux configured as the attacking machine. Additional machines can be added later and used as targets for authorized security testing.
